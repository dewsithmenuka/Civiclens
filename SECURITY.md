# Security Policy

## Reporting a vulnerability
Please do **not** open a public issue. Email the maintainers (add your address here) or use
GitHub's private "Report a vulnerability" feature. You'll get an acknowledgement within 72 hours.

## Supported versions
Only the latest release receives security fixes.

## Design summary
See [docs/security.md](docs/security.md) for the threat model and controls
(Argon2id, rotating refresh tokens with reuse detection, RBAC, rate limiting, approximate public coordinates).
